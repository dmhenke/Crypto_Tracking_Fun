# Archive

Retired files kept for the record; nothing here is published or run.

- `eth_predict.py`, `daily_report.json`, `backtest_chart.html`: an earlier Prophet-based weekly ETH forecast and its backtest (26 forecasts, 2025-12-26 to 2026-06-19). Only 2 of 26 predicted ranges contained the price a week later (8%). Mean absolute error was $1,135, against $136 for assuming no change. Nineteen ranges sat entirely above the current price, and one predicted a negative price. The dashboard's Forecast tab replaces it with simple models whose coverage is measured and published.
- `analysis.py`: an earlier, corrupted copy of the same script (does not run).
