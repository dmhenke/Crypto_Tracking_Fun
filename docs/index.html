    Method

    • Returns: log returns on dates both series have a price. Weekly and monthly returns use the last matched price in each week (Monday start) or calendar month.
    • Normal theory: OLS t intervals for beta and alpha, a Fisher-z interval for correlation, χ² intervals for volatility, and t intervals for the mean, as in R's lm, cor.test and t.test.
    • Newey-West: heteroskedasticity- and autocorrelation-consistent standard errors (Bartlett kernel, lag ⌊4(n/100)2/9⌋) for beta, alpha and the mean. Correlation and volatility fall back to normal theory.
    • Block bootstrap: 1,000 moving-block resamples (block length ≈ n1/3, fixed seed) with percentile intervals for every statistic. It makes no normality assumption and keeps short-run dependence.
    • Validation: tests/validate_stats.R checks this code against R (lm, confint, cor.test, t.test, anova, sandwich::NeweyWest, pt, pf, qchisq, prop.test) on every push.

    Correlation matrix

    Pairwise Pearson correlation of log returns over the chosen window, each pair on its own matched dates. Hover a cell for the 95% interval and the number of observations.

    Rolling volatility

    Annualized standard deviation of daily log returns over a trailing window (√365 for coins, √252 for funds).

    What if I had invested?

    A hypothetical, using daily closing prices: no taxes, no slippage, fractional units allowed. It shows how the choice of vehicle (coin vs. fund, high-fee vs. low-fee) changes the outcome. It is not a recommendation.

    Forecast ranges, scored honestly

    These models don't predict direction. They give a range the price is likely to land in, and every past forecast is scored against what actually happened. Trust a range only as far as its measured coverage.

    Backtest scoreboard

    Rolling-origin backtest over the whole history: at each non-overlapping origin, each model forecasts using only data available then. Coverage is the share of actual prices that landed inside the stated range; a well-calibrated 80% range covers about 80%. Coverage intervals are Wilson 95% intervals.

    Why the earlier ETH forecast was removed This project previously published a Prophet-based weekly ETH forecast (26 forecasts, 2025-12-26 to 2026-06-19). Only 2 of its 26 predicted ranges contained the actual price a week later (8%). Its average error was $1,135, against $136 for simply assuming no change. Nineteen of the 26 ranges sat entirely above the current price, and one predicted a negative price. Those files are kept in archive/ for the record. This tab replaces them with simple models whose accuracy is measured and published.
