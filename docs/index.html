Daily return relationships (trailing 365 days)

OLS beta of daily log returns and Pearson correlation, each with a 95% confidence interval. Volatility is annualized on 252 days for pairs involving a trust and 365 days for crypto-only pairs.
Coinbase daily bars close at 00:00 UTC and NYSE at 16:00 ET, so same-date returns are offset by 3–4 hours, and weekend crypto moves land in the trusts' Monday return. Both effects pull the trust betas and correlations below 1. Heavy-tailed returns make the normal-theory intervals somewhat optimistic.

Annualized volatility (trailing 365 days)

95% interval from the χ² distribution of the sample variance; crypto annualized on 365 days, trusts on 252.
